# Tumble Toy — 게임플레이 스펙

> 2026-10-03: 특수 블록, 2–3층, 아이템, 연쇄 Undo, 시간 메달, 입력 수 기준 par 및 100스테이지는 [캠페인 스펙](campaign-spec.md)을 우선 적용한다. 기존 고정 시작 방향과 숫자 일치 규칙은 유지한다.

## GS-01: 보드

- 보드는 정사각형 격자로 구성한다.
- `#`는 이동 가능한 블록 타일, `.`는 빈 공간이다.
- 주사위는 타일의 중심에 한 칸만 점유한다.
- 시작 타일은 일반 바닥 타일 위에 민트색 출발 마커를 겹쳐 표시한다. 주사위가 시작 타일에 있으면 마커는 주사위 뒤에 표시한다.

### 검증 기준

- 이동 가능한 타일에서만 주사위가 멈춘다.
- 타일 밖으로 이동하려는 입력은 위치나 주사위 방향을 변경하지 않는다.
- 시작 위치는 목표 타일과 구분되며, 첫 화면에서 즉시 식별할 수 있다.

## GS-02: 표준 주사위

- 주사위는 1–6을 한 번씩 갖는다.
- 마주 보는 면의 합은 7이다: 1↔6, 2↔5, 3↔4.
- 모든 레벨은 다음 시작 방향을 사용한다: 윗면 1, 아랫면 6, 북쪽 2, 남쪽 5, 동쪽 3, 서쪽 4.
- 한 번의 입력은 정확히 한 칸의 회전을 의미한다.

### 검증 기준

- 오른쪽으로 굴리면 기존 서쪽 면이 윗면이 된다.
- 왼쪽으로 굴리면 기존 동쪽 면이 윗면이 된다.
- 위쪽으로 굴리면 기존 남쪽 면이 윗면이 된다.
- 아래쪽으로 굴리면 기존 북쪽 면이 윗면이 된다.
- 같은 방향으로 네 번 굴리면 원래 방향으로 돌아온다.
- 3D 보드 갱신, Undo, 재시작 뒤에도 규칙 상태와 화면의 주사위 면 배치가 일치한다.

## GS-03: 목표 타일과 클리어

- 목표 타일에는 요구 숫자 1–6이 있으며, 3D 보드에서는 목표색 블록 상단에 해당 숫자의 주사위 점 패턴 텍스처로 표시한다.
- 주사위가 목표 타일에 있고 윗면이 요구 숫자와 같으면 레벨을 클리어한다.
- 숫자가 다르면 플레이는 계속된다.

### 검증 기준

- 숫자가 일치하지 않은 목표 타일 도착은 클리어 화면을 표시하지 않는다.
- 숫자가 일치한 목표 타일 도착은 클리어 화면을 표시한다.

## GS-04: 이동 수와 완벽 클리어

- 유효 타일로 한 칸 이동할 때마다 이동 수를 1 증가시킨다.
- 각 레벨에는 목표 이동 수(`par`)가 있다.
- 목표 숫자를 맞춰 클리어했고 이동 수가 `par` 이하이면 완벽 클리어다.

### 검증 기준

- 클리어 결과 UI는 일반 클리어와 완벽 클리어를 서로 다른 문구 또는 시각 요소로 구분한다.
- 완벽 클리어 결과 UI에는 실제 이동 수와 `par`를 함께 표시한다.

## GS-05: 낙하·언두·재시작

- 빈 공간 또는 보드 밖으로의 이동은 낙하 시도로 취급한다.
- 낙하 시도 후에는 마지막 안전 상태(현재 위치·방향·이동 수)를 유지한다.
- 언두는 가장 최근의 유효 이동 하나를 되돌린다.
- 언두는 주사위가 이전 타일과 이전 면 배치로 한 칸 굴러 돌아가는 애니메이션으로 표시한다.
- 각 레벨에서 Undo는 최대 3회만 사용할 수 있으며, 재시작 또는 다음 레벨 시작 시 사용 횟수를 초기화한다.
- 클리어 카드가 표시된 뒤에는 언두를 사용할 수 없다. 재시작으로 현재 레벨을 다시 시작할 수 있다.
- 재시작은 시작 위치와 시작 방향, 이동 수 0으로 복원한다.

## GS-06: 정보 전달

- 헤더는 현재 이동 수, 목표 이동 수, 현재 윗면을 보여준다.
- 인접한 이동 가능 블록은 활성 상태로 강조하고, 해당 블록 위에 이동 후 윗면 숫자를 표시한다.
- 유효 이동, Undo, 재시작 뒤에는 현재 주사위 위치를 기준으로 활성 블록을 즉시 다시 계산한다.
- 플레이어는 활성 블록을 직접 터치해 해당 블록으로 이동한다.
- 현재 목표 숫자는 목표 타일과 하단 UI에 표시한다.

### 검증 기준

- 이동 가능한 인접 블록마다 다음 윗면 숫자가 표시된다.
- 활성 블록 외의 보드 터치는 이동 상태를 변경하지 않는다.

## GS-07: 피드백과 레벨 전환

- 유효 이동은 주사위의 위치·윗면·이동 수 갱신으로 즉시 피드백한다. 별도 이동 애니메이션은 후속 스펙이 승인되기 전까지 범위가 아니다.
- 낙하 시도는 짧은 시각 피드백과 안내 문구를 표시하되 안전 상태를 변경하지 않는다.
- 클리어 카드가 표시된 상태에서는 Enter, Space 또는 카드/다음 레벨 조작을 통해 다음 레벨로 진행한다.
- 재시작은 클리어 상태에서도 사용할 수 있으며 현재 레벨을 초기 상태로 복원한다.
- 모바일 하단 컨트롤의 좌측에는 종료·재시작·Undo를 한 줄로 배치한다. 우측 방향 화살표는 상·하·좌·우가 식별되는 십자 배치로 표시한다.
- 종료 버튼은 게임 실행을 종료한다.
- Undo 컨트롤은 남은 사용 횟수를 표시하고, 3회를 모두 사용하면 비활성 상태로 표시한다.

### 검증 기준

- 낙하 시도 뒤 위치·방향·이동 수가 직전 안전 상태와 동일하다.
- 클리어 상태에서 임의의 보드/화면 터치만으로 다음 레벨로 진행하지 않는다.
- 재시작 뒤 클리어 카드가 사라지고 이동 수가 0이 된다.
- 360×800 기준에서 모든 하단 컨트롤이 화면 안에 표시되고, 서로의 터치 영역이 겹치지 않는다.

## GS-08: 스플래시와 홈 화면

- 시작 시 스플래시 화면에는 게임 제목과 로딩 표시를 표시한다.
- 리소스 초기화와 최소 3초 노출이 끝나면 `화면을 터치하세요` 안내를 점멸한다.
- 준비 완료 뒤 터치, 클릭, Enter 또는 Space를 누르면 홈 화면으로 전환한다.
- 홈 화면에는 게임 제목, 캠페인 진행도, 이어하기 또는 새 게임, 튜토리얼, 스테이지 선택과 설정 진입을 표시한다.
- 홈 화면의 이어하기·새 게임 버튼 또는 Enter·Space를 누르면 첫 미완료 스테이지를 시작한다.

### 검증 기준

- 초기 실행은 보드가 아닌 스플래시 화면을 표시한다.
- 준비가 끝난 스플래시 → 홈 → 첫 미완료 스테이지 전환이 입력 한 번씩으로 완료된다.
- 홈 화면에서 시작하지 않은 경우 게임 보드 입력이 처리되지 않는다.

## GS-09: 모바일 UI 레이아웃

- 기준 캔버스는 세로 360×800이며, 화면 가장자리에서 최소 16px의 시각 여백을 유지한다.
- 주요 터치 컨트롤의 높이는 최소 44px이다. 하단 컨트롤 바는 바닥에서 36px 이상 떨어뜨려 제스처 영역과 분리한다.
- 모바일 화면에 표시되는 안내 문구는 키보드 키를 전제로 하지 않고 탭·버튼 중심으로 작성한다. 키보드 입력은 보조 입력으로만 유지한다.
- 하단에 별도 패널·영역을 만들지 않는다. 안내, 목표 정보, 컨트롤은 장난감방 배경 위에 직접 표시한다.
- 보드는 화면 수직 중앙을 기준으로 배치한다. 헤더와 하단 컨트롤을 침범하지 않도록 보드의 행 수에 맞춰 여백을 유지한다.

### 검증 기준

- 스플래시·홈·플레이 화면의 주요 패널과 터치 컨트롤이 360×800 화면 경계 안에 있다.
- 종료·재시작·Undo·네 방향 화살표의 터치 영역은 모두 44px 이상 높이이며 서로 겹치지 않는다.
- 스플래시와 홈 화면의 표시 문구에 PC 키보드 입력만을 전제로 한 안내가 없다.
- 플레이 화면에 하단 UI를 감싸는 별도 패널 배경이 없고, 보드 중심선이 화면 세로 중심선과 일치한다.

## GS-10: 실제 3D 보드 렌더링

- 보드 타일, 목표 타일, 시작 마커, 플레이어 주사위는 Godot 3D 노드와 메시로 렌더링한다.
- 카메라는 고정 쿼터뷰이며, 보드 중심을 향한다.
- 게임 규칙용 위치·방향·이동 수는 기존 격자 상태를 정본으로 유지한다. 실제 물리 굴림으로 규칙 상태를 결정하지 않는다.
- 2D UI는 3D 보드 위에 오버레이로 표시한다.
- 3D 주사위의 면에는 표준 주사위 숫자를 점으로 표시한 투명 배경 텍스처를 입힌다. 초기 면 배치는 GS-02의 시작 방향을 따른다.
- 현재 레벨의 목표 숫자와 일치하는 주사위 면만 목표색으로 표시해 맞춰야 할 면을 구분한다.
- 인접한 3D 바닥 블록 사이에는 배경이 보이는 균일한 간격을 둬 이동 가능한 셀 경계를 식별할 수 있게 한다.

### 검증 기준

- 플레이 화면에서 3D 카메라·조명·메시가 활성화되고, 주사위와 타일의 윗면·측면을 구분할 수 있다.
- 주사위 위치가 유효 이동, Undo, 재시작 시 격자 상태와 일치한다.
- 3D 보드가 헤더·하단 컨트롤의 2D UI 가독성을 가리지 않는다.

## GS-11: 주사위 굴림 애니메이션

- 유효 이동 시 주사위는 다음 타일로 회전하며 이동하는 3D 애니메이션을 재생한다.
- 애니메이션 중에는 추가 이동 입력을 처리하지 않는다.
- 착지 효과음은 애니메이션 종료 시 한 번 재생한다.
- 회전 축은 보드 월드 좌표에 고정한다. 좌우 이동은 Z축, 상하 이동은 X축을 기준으로 회전한다.

### 검증 기준

- 유효 이동마다 주사위의 위치와 회전이 시각적으로 변화한다.
- 애니메이션 중 연속 입력으로 두 칸 이상 이동하지 않는다.
- 애니메이션 종료 뒤 주사위 위치가 규칙 상태의 현재 위치와 일치한다.

## GS-12: 개발 버전 보존과 최종 3D 실행

- 초기 버전은 `2D 탑뷰`, 중기 버전은 `2D 쿼터뷰`, 최종 버전은 `3D`로 보존한다.
- 실제 게임은 최종 3D로 시작하고 홈 화면, 스테이지 선택, 플레이 HUD에 버전 선택 버튼을 표시하지 않는다.
- 내부 검증용 PC 숫자 키 1·2·3은 각각 초기, 중기, 최종 버전으로 전환한다.
- 2D 탑뷰는 정사각 격자와 코드 도형으로 보드, 목표, 시작점, 주사위 윗면과 특수 타일을 표시한다.
- 2D 쿼터뷰는 생성된 PNG 리소스로 바닥, 목표, 시작점, 주사위, 배경과 아이콘을 표시한다.
- 최종 3D는 `SubViewport`, 직교 카메라, 조명, 메시와 주사위 면 텍스처를 실제로 렌더링한다.
- 보기 전환은 표시 계층만 바꾸며 `Rules`의 상태와 캠페인 진행을 변경하지 않는다.
- 다층 레벨의 층 미리보기와 현재 층 복귀는 세 보기에서 동일하게 동작한다.

### 검증 기준

- 새 실행에서 홈 화면의 시작 버튼을 누르면 최종 3D로 플레이한다.
- 홈과 플레이 화면에 초기·중기·최종 버전의 이름이나 선택 상태가 표시되지 않는다.
- 임의의 이동 이후 보기 1→2→3→1을 전환해도 위치, 방향, 이동 수, 타이머, 인벤토리와 Undo 기록이 동일하다.
- 각 보기는 360×800의 보드 안전 영역 안에서 같은 스테이지를 표시한다.
- 3D 선택 시 3D 뷰포트가 갱신되고 화면에 표시되며, 다른 보기에서는 불필요한 3D 렌더 갱신을 중단한다.
- 실제 MVP는 3D로 시작하고 버전 선택 UI를 노출하지 않는다.
- 명령행 `--view=top`, `--view=quarter`, `--view=3d`는 내부 캡처와 회귀 검증에만 사용한다.

## GS-13: 메인 메뉴, 진행 잠금과 설정

- 메인 메뉴는 픽셀 장난감방 팔레트와 공통 9-slice UI를 사용해 제목, 현재 진행도, 이어하기, 스테이지 선택, 튜토리얼, 설정을 한 화면에 배치한다.
- 제목은 단순 문서형 헤더가 아니라 게임 로고처럼 계층과 강조색을 갖춘다.
- 이어하기는 첫 미완료 스테이지를 최종 3D로 시작한다.
- 스테이지 선택에서는 클리어한 스테이지를 다시 선택할 수 있고, 마지막 연속 클리어 지점의 다음 스테이지 1개를 새 도전으로 선택할 수 있다.
- 나머지 스테이지는 잠금 표시와 낮은 대비를 사용하며 터치 입력을 무시한다.
- 설정은 BGM과 효과음 음량을 0·25·50·75·100%로 조절하고 안내 음성을 켜거나 끈다.
- 설정은 `user://settings-v1.json`에 저장하고 게임 진행 기록과 분리한다.

### 검증 기준

- 새 기록에서는 001만 선택할 수 있고 002 이후는 잠겨 있다.
- 001을 클리어하면 001 재도전과 002 새 도전이 가능하고 003 이후는 잠겨 있다.
- 잠긴 카드를 눌러도 화면이나 현재 레벨이 바뀌지 않는다.
- BGM·효과음 변경은 현재 재생기에 즉시 반영되며 안내 음성을 끄면 이후 음성 안내가 재생되지 않는다.
- 설정 화면을 닫고 다시 열거나 앱을 다시 실행해도 저장한 값이 유지된다.

## GS-14: 시작 스플래시

- 앱 실행 직후 픽셀 장난감방 배경, 게임 로고, VIS-211 주사위 보드 비주얼과 로딩 표시를 사용한 스플래시를 표시한다.
- 리소스 초기화와 최소 3초 노출이 모두 끝나면 로딩 완료 상태와 점멸하는 터치 안내를 표시한다.
- 준비 완료 뒤 터치·클릭·Enter·Space 입력으로 메인 메뉴에 진입하며, 입력 전에는 스플래시를 유지한다.
- 준비 완료 전에는 메뉴와 게임 플레이 입력을 처리하지 않는다.
- 내부 비교용 숫자 키 1·2·3은 스플래시에서도 계속 동작한다.

### 검증 기준

- 새 실행의 첫 화면은 메인 메뉴가 아니라 스플래시다.
- 2.9초까지 스플래시가 유지되고, 3초와 초기화 완료 뒤에도 입력 전까지 메인 메뉴로 전환되지 않는다.
- 준비 완료 전 화면을 터치해도 조기 전환이나 게임 시작이 발생하지 않는다.
- 준비 완료 뒤 화면을 터치하면 메인 메뉴로 전환된다.

## GS-15: 화면별 배경음악

- 스플래시, 메인 메뉴, 튜토리얼, 설정과 스테이지 선택에서는 메뉴 전용 BGM을 반복 재생한다.
- 스테이지에 들어가면 퍼즐 전용 BGM으로 전환하고, 목록이나 메인 메뉴로 돌아가면 메뉴 BGM으로 전환한다.
- 같은 화면 그룹 안에서 페이지를 이동할 때 현재 BGM을 처음부터 다시 시작하지 않는다.
- 두 BGM은 설정의 배경음악 음량을 함께 적용받는다.

### 검증 기준

- 새 실행의 스플래시에서 메뉴 BGM이 재생되고 재생 위치가 증가한다.
- 스테이지 시작 시 퍼즐 BGM으로 바뀌고, 목록으로 돌아가면 메뉴 BGM으로 바뀐다.
- 메인 메뉴에서 튜토리얼·설정·스테이지 선택으로 이동해도 메뉴 BGM의 재생 위치가 유지된다.
