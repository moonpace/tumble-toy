# 100 스테이지 캠페인 (2026-10-03)

이 문서는 대화에서 승인된 확장 규칙의 기준이며 이전 문서의 10레벨/TBD 제한을 대체한다.

## 규칙

- 고정 시작 면: 위1 아래6 북2 남5 동3 서4. 목표 좌표/층과 윗면 숫자가 모두 일치하고 필수 별을 수집하면 클리어.
- 일반 바닥은 무한 내구도. 내구도/균열 얼음은 떠날 때 1 감소하며 0이면 파괴.
- 초기 맵은 각 층마다 연결되어 있고 둘러싸인 빈 공간이 없다. 벽은 바닥 위 장애물이다. 층 사이 공간과 플레이 중 파괴는 허용.
- 숫자 포털은 일치할 때 연결된 층/좌표로 전송. 계단은 무조건 전송. 방향 유지, 착지 즉시 재전송 금지.
- 찍찍이는 3초 이동 잠금. 화염은 사망. 전기는 진입 방향으로 구르지 않고 끝까지 밀림. 얼음은 진입 방향으로 칸마다 구르며 벽/맵 끝까지 이동. 강제 이동 중 만나는 효과는 적용하고 포털/찍찍이에서는 정지. 막힌 일반 이동은 무효. 파괴된 바닥으로 진입하면 사망.
- 숫자 스위치는 일치할 때 문을 개방. 다리 스위치는 다리 활성화를 토글. 회전판은 수평 90도 회전. 화살표는 나갈 수 있는 방향 제한. 별은 표시 숫자에 일치할 때 수집.
- 방열/논슬립/절연 장비는 해당 효과를 1회 자동 무효화. 수리 키트는 현재 및 인접 내구도 블록을 1 보강. 회전 토큰은 수평회전. 귀환 실타래는 시작점 복귀(방향 유지, 시작점 파괴 시 사용 불가). 숫자 열쇠는 윗면이 맞는 문 통과 시 소비. 시간 지우개는 찍찍이 즉시 해제. 되감기 아이템은 추가 Undo 1회.
- 필요한 아이템은 맵에 고정 배치. 재시작으로 모두 복원. 하나의 입력 및 강제 연쇄 이동은 Undo 하나로 복구. 사용한 Undo 횟수와 경과시간은 복구하지 않는다.
- 이동 수는 유효 방향 입력/능동 아이템 사용 횟수. 강제 이동 및 전송은 추가 입력을 세지 않는다.
- 10/20/.../100은 첫 유효 이동부터 타이머 시작. 찍찍이 대기는 포함, 이동 연출 시간은 제외. 시간 초과도 일반 클리어 가능. 일시정지/포커스 상실 시 보드를 가리고 시간을 멈춤. 힌트 사용 시 해당 시도의 시간 메달은 제외.
- 층 미리보기 중 시간은 흐르고 이동 불가. 현재 층 복귀 후 이동. 각 층 바닥/주사위 전체가 HUD 사이 영역에 들어오도록 카메라 자동 맞춤.
- 클리어/최소입력/최고시간/메달은 로컬 저장. 100개 스테이지 선택 및 테마별 설명 제공.

## 테마

1–10 장난감 방 / 11–20 과자집 / 21–30 우주 정거장 / 31–40 사탕 숲 / 41–50 화산 / 51–60 로봇 공장 / 61–70 얼음 왕국 / 71–80 시계탑 / 81–90 하늘 정원 / 91–100 마법사의 성.

## 검증/완료 조건

- 구조 다양성 개정: 숫자·목표·특수 타일 종류를 제외한 실제 바닥 윤곽도 100개 모두 달라야 한다. 이동/회전/좌우반전으로 같은 윤곽은 중복으로 간주한다. ㄴ자, T자, 엇갈린 방, 좁은 연결부, 계단, ㄷ자, 십자, 가지, 두 방, 빗살의 10가지 지형을 사용하고 층별 입구/출구를 이동 거리 기준으로 배치한다. 특수 블록은 이 경로 위에 배치한다.

- 100개 고정 레벨은 제작용 결정적 템플릿으로 생성하여 JSON에 저장. 실행 시 랜덤 생성하지 않는다.
- 실제 게임과 동일한 순수 상태 전이 엔진으로 탐색. 층/방향/내구도/수집/스위치/인벤토리를 방문 상태에 포함.
- Undo 없이 검증된 해법을 저장하고 전체 재생 테스트. par는 해법 입력 수. 시간 메달 한도는 연출 제외 해법 입력당 3초 + 강제대기 + 20초로 초기 설정. 인간 플레이 밸런싱은 별도 필요.
- 메커니즘 단위 테스트, 100개 해법 재생, 초기 구멍/연결/층별 화면 투영 검증, 메인 실행 후 기존 시뮬레이터 교체 확인.
