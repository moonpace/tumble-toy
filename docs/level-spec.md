# Tumble Toy — 레벨 스펙

이 문서는 초기 10개 레벨의 기록이다. 현재 실행되는 100개 레벨의 정본은 `data/campaign.json`이며, 각 레벨에 층별 타일·아이템·숫자 조건·검증된 해법·par·시간 한도가 저장되어 있다. 확장 규칙은 [캠페인 스펙](campaign-spec.md)을 따른다. 아래 기존 좌표는 `Vector2i(x, y)`이며, 맵의 첫 행·첫 열은 0부터 시작한다. `#`는 바닥 타일, `.`는 빈 공간이다.

모든 레벨은 `gameplay-spec.md` GS-02의 고정 시작 방향을 사용한다.

레벨 2 이후에는 목표를 향해 진행할 때 선택할 수 있는 분기 또는 우회 경로를 하나 이상 제공한다. 한 칸 폭의 단일 복도만 따라가야 하는 맵은 사용하지 않는다.

## 검증 기준

- 모든 시작·목표 좌표는 해당 레벨의 `#` 타일이다.
- 각 레벨에는 요구 윗면을 만족하는 해법이 하나 이상 있다.
- 모든 맵의 바닥 타일 경계 내부에는 빈 공간이 없다.
- 레벨 4–10은 진행 중 선택할 수 있는 갈림길(인접 바닥 타일이 세 칸 이상인 지점)을 하나 이상 가진다.
- 표의 최적 이동 수는 고정 시작 방향과 GS-02 회전 규칙으로 계산한 최단 해법이다.
- `par`는 최적 이동 수보다 작지 않다.
